# SILVA — 心理戦カードゲーム

手札はたった1枚。相手の手札を読み、生き残れ。
日本の職人文化と森の精霊をテーマにした、無料・インストール不要のブラウザカードゲーム。

**FOMUS × KUKU PROJECT**

## 構成

```
public/
  game-core.js   ルールエンジン（唯一の正典。サーバーとブラウザで共有）
  i18n.js        多言語辞書（日本語 / English）
  local-game.js  ブラウザ内AI対戦（サーバー不要・オフライン可）
  index.html     ゲーム本体（PWA）
  rules.html     ルール説明
  sw.js          Service Worker
server.js        オンライン対戦サーバー（Express + ws）。ネットワーク層のみ
test/            回帰テスト（ルール判定・多言語・オンライン対戦）
```

- **ルールは `game-core.js` だけが持つ。** サーバーもブラウザAIも同じ実装を使うので判定がズレない
- **AI対戦はブラウザ内で完結する。** サーバーに繋がないため、一人プレイの運用コストはゼロ
- 対局ログは `{k:キー, ...引数}` の構造化データ。表示言語はクライアントが決める

## 開発

```bash
npm install
npm start        # http://localhost:3000
npm test         # ルール判定59件 + WS統合11件 + オンライン対戦14件
```

## リリース手順

**必ず `DEPLOY.md` のチェックリストに従うこと。** 特に：

1. `npm test` を通す（ルール判定・翻訳漏れ・バージョン同期を機械検査する）
2. `public/sw.js` の `CACHE_NAME` を上げる
3. コアJSを変更したら `index.html` / `rules.html` の `?v=` と `sw.js` の `ASSET_VER` を上げる
   （ズレはテストが検出する）

## ルールの変更について

カード効果・勝敗判定を変えるときは、必ず次の3点を同時に更新する：

1. `public/game-core.js`（実装）
2. `public/rules.html`（説明。日本語）＋ `public/i18n.js`（英語対訳）
3. `test/rules.test.js`（期待値）

表示と実装のズレはテストが検出するが、**仕様の意図はコミットメッセージに残すこと**。
（例：ククノチを斬れるのは刀の少女の一閃だけ。少年2枚目・戦士では再生する）
